# Brownhaute landing page
React + Vite + Tailwind + framer-motion.

    npm install
    npm run dev        # local preview
    npm run build      # outputs dist/ — upload to Netlify / Vercel / any host

Edit contact details, TikTok link and map location in the CONFIG block at the top of `src/App.jsx`
(WHATSAPP, PHONE_DISPLAY, PHONE_TEL, CITY, TIKTOK, MAP_QUERY). Replace MAP_QUERY with the exact
studio address when available. Photos live in `public/images`.
